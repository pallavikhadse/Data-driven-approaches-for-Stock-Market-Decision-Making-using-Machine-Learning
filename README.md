# Data-driven-approaches-for-Stock-Market-Decision-Making-using-Machine-Learning
An intelligent Machine Learning system designed for Stock Market Anomaly Detection and decision-making. By integrating Sentiment Analysis of financial news with unsupervised models like Isolation Forest and One-Class SVM, this project identifies market irregularities and potential turning points to assist in risk management and profit booking.
